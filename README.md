# Statistics for Data Science in Python

Practice notebooks from my statistics for data science learning, worked through in Python.

## What's Inside

- Statistics notebooks (26th Statistics, 4th, 346 notebook)
- Descriptive statistics, distributions and probability practice

## Tech Stack

Python, Pandas, NumPy, Matplotlib, SciPy, Jupyter Notebook

## How to Run

1. Clone the repository
2. Install the libraries: `pip install jupyter pandas numpy matplotlib scipy`
3. Open the notebooks with `jupyter notebook` and run the cells in order
